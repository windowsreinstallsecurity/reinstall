    You ran an infostealer.
    Here's exactly how to fix it.

    Infostealers scrape saved passwords, browser cookies, autofill data, crypto wallets, and session tokens, then send them to an attacker. Antivirus alone can't guarantee removal, because you can't be certain everything it touched is gone. The reliable fix is to wipe the drive and reinstall Windows from scratch. This guide walks through the whole process, from the moment you realize something's wrong to being fully back up and running.

    ⛔ Do this in the next 5 minutes
    • Disconnect the infected device from the internet — pull the ethernet cable or turn off Wi-Fi. This stops the malware from sending out any more data or downloading follow-up payloads.
    • Don't log into anything else on this device. Every password you type on a compromised machine can be captured. Do your password changes later, from a different, clean device (a phone on mobile data works).
    • Don't panic-delete files. Deleting things at random won't remove the infection and can make it harder to recover anything you need. A full reinstall handles this properly.
    01

    No other computer available? Here's how to make the media safely on the infected PC

    Building the installer on a clean device is the ideal, but it isn't always possible. If this infected machine is the only computer you have, you can still create the USB installer on it — the key is to treat it as one short, single-purpose task, not a return to normal use.

    ℹ Why this is still reasonably safe

    An infostealer is after data it can capture while you're logged into accounts or typing credentials — it isn't going to corrupt the Windows ISO you download or sabotage a USB drive. As long as you don't log into anything or enter any passwords during this window, there's very little for it to grab, and the reinstall in step 06 wipes the machine clean regardless.

    ⚠ Stay focused on the one task

    Resist the urge to check email or social media "while you're online anyway." This window should be: reconnect → download two files in a private window → verify → disconnect. Once the USB drive is built, continue with the rest of this guide exactly as written — everything from here on works the same regardless of which machine made the installer.

    02

    Back up your files — carefully

    Reinstalling Windows erases the drive, so grab what you need first. The goal is to save your personal files without dragging the infection along with them.

    Safe to back up

    ⚠ Leave these behind
    • Browser profiles, saved passwords, and cookies — this is exactly what the infostealer targeted. Don't copy your browser's user data folder to your new install.
    • .exe, .msi, .bat, .scr, or unfamiliar installer files — don't carry over anything you downloaded around the time things started acting weird.
    • Anything from your Downloads folder you don't specifically recognize and need.

    How to move it over

    Copy your personal files to a USB drive or external hard drive (a different one from the one you'll use for Windows in the next step). Once you're on your freshly installed, clean system, plug the backup drive in and let your antivirus scan it before you open anything from it. This catches the rare case where a document itself was booby-trapped.

    03

    Download an official Windows ISO

    Always get your installer straight from Microsoft — never from a third-party "download" site, which is a common way people get reinfected. If you're not sure which version you're licensed for, Windows 11 is the safe default for any PC made in the last few years; Windows 10 still receives support if your hardware doesn't meet Windows 11's requirements.

    Windows 11

    Official Microsoft download page — choose "Download Windows 11 Disk Image (ISO)."

    Windows 10

    Official Microsoft download page — choose "Download Windows 10 Disk Image (ISO)."

    Get Windows 10 ISO ↗

    On the Microsoft page

    Select your edition, choose your language, then click 64-bit Download. The file is roughly 5–6 GB, so give it time depending on your connection. Save it somewhere you'll find it again, like your Desktop or Downloads folder — you'll point Rufus at this file in the next step.

    ℹ Do this from a clean device if possible

    If you have a second computer or can borrow one, download the ISO and build the USB drive there instead of on the infected machine. That way nothing from the infected system touches your installer.

    04

    Turn a USB drive into a Windows installer with Rufus

    You'll need a USB flash drive with at least 8 GB of space. Everything currently on it will be erased, so back it up first if it has anything on it.

    Get Rufus

    Rufus is a small, free, open-source tool that writes an ISO to a USB drive and makes it bootable.

    Download Rufus ↗

    Grab the regular version (not "portable" unless you prefer that) from the Download section of rufus.ie. No installation needed — it just runs.

    Rufus settings, step by step

    FieldWhat to set
    DeviceSelect your USB drive from the dropdown. Double-check the drive letter and size so you don't pick the wrong disk.
    Boot selectionClick SELECT and choose the Windows ISO file you downloaded.
    Partition schemeGPT — correct for virtually all PCs made since ~2012 (UEFI firmware).
    Target systemUEFI (non-CSM)
    File systemNTFS (Rufus will pick this automatically for Windows ISOs over 4 GB)
    Volume labelLeave as default, or name it something like WIN_INSTALL

    If you genuinely have an older BIOS-only (not UEFI) machine, use MBR and BIOS or UEFI instead — but for anything from the last decade, GPT + UEFI is correct.

    Write it

    Click START. Rufus may ask whether to download some additional UEFI files — you can decline unless prompted otherwise. It will warn you that all data on the drive will be destroyed — confirm, since that's expected. Writing usually takes 5–15 minutes. When the status bar shows READY, it's done and safe to eject.

    05

    Boot your PC from the USB drive

    Plug the USB drive into the infected computer, restart it, and interrupt the normal boot process to pick the USB drive instead. The key you press depends on the manufacturer — tap it repeatedly right as the PC powers on.

    ManufacturerBoot menu key
    DellF12
    HPF9 or Esc
    LenovoF12 or Novo button
    ASUSF8 or Esc
    AcerF12
    MSIF11
    Custom-built / motherboard BIOSUsually F11 or Del for full BIOS setup

    From the boot menu

    Select the entry matching your USB drive's name (it may show up twice — if so, pick the one labeled UEFI). Press Enter. You should land on the "Windows Setup" screen with a language selector.

    ⚠ Nothing happens?

    If the PC just boots into your old Windows instead of the USB menu, the boot order in BIOS may be putting the internal drive first, or Secure Boot / Fast Boot may be interfering. Restart, enter BIOS setup directly (often Del or F2 at power-on), and either change the boot order or use the one-time boot menu option from there.

    06

    Install Windows — a real clean install

    The part that actually matters for removing the infection: when you get to the drive selection screen, you need to delete the existing partitions rather than choosing "keep my files." Keeping files defeats the purpose of the reinstall.

    ⛔ Double-check the drive

    If you have more than one drive installed, confirm you're deleting partitions on the correct one. External backup drives should stay unplugged during this step so there's no chance of picking the wrong disk.
